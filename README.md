# Frigurso FootGolf · Mundialito Match Play Elite 2026
PWA independiente (no comparte nada con las otras apps Frigurso). 64 jugadores, 16 grupos de 4, eliminación directa.
Servidor: Supabase propio (tablas `mm_*` + funciones RPC; el SQL vive fuera de este repo). Config: reemplazar `__SB_URL__` y `__SB_KEY__` en `index.html` (la anon key es pública por diseño).
